# TotkCave Library

[![NuGet](https://img.shields.io/nuget/v/TotkCave.svg)](https://www.nuget.org/packages/TotkCave)
[![License: GPL-3.0-or-later](https://img.shields.io/badge/license-GPL--3.0--or--later-blue.svg)](LICENSE)

`TotkCave` is a **.NET 10** class library for parsing, decompressing, decoding, building 3D meshes, and exporting Wavefront `.obj`/`.mtl` files for *Tears of the Kingdom* cave (`cave017`) and Depths terrain (`.quad`) files.
